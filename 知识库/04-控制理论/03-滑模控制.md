# 滑模控制 (Sliding Mode Control) 及其在VMC中的应用

## 1. 一句话定义
> 滑模控制 (SMC) 是一种**鲁棒非线性控制方法**，通过设计"滑模面"和"切换控制律"，迫使系统状态沿着预定曲面"滑行"到目标点。它最大的优势是对**模型不确定性和外部扰动**具有极强的鲁棒性，因此特别适合VMC中路面附着变化、轮胎参数不准等场景。

## 2. 核心概念与公式

### 2.1 基本思想

```
滑模控制的三要素:

  1. 滑模面 s(x) = 0
     定义了"好的动态行为"
     当s(x)=0时, 系统按照我们设计的动态衰减到目标

  2. 趋近律 ṡ = -K·sgn(s)  (或其他)
     迫使状态向滑模面"趋近"

  3. 等效控制 + 切换控制
     u = u_eq + u_sw
     u_eq: 让系统留在滑模面上的控制 (基于名义模型)
     u_sw: 克服不确定性的切换项

物理直觉:
  ┌─────────────────────────────────────────┐
  │  就像滑雪:                              │
  │  滑模面 = 雪道 (你想沿着滑的路径)        │
  │  切换控制 = 你的腿不断调整平衡           │
  │  扰动 = 雪地上的冰斑/凹凸               │
  │  "不管雪地多不平, 你总能回到雪道上"     │
  └─────────────────────────────────────────┘
```

### 2.2 SMC用于DYC的完整推导

```python
# 步骤1: 定义滑模面
# DYC常用滑模面:
#   s = (r - r_ref) + ξ·(β - β_ref)
#   或更简单: s = r - r_ref

# 为什么加β项?
#   纯r滑模可以跟踪横摆角速度, 但β可能发散
#   加入β项 = "跟踪r的同时不要让β太大"

# 步骤2: 对滑模面求导
# s = (r - r_ref) + ξ·(β - β_ref)
# ṡ = (ṙ - ṙ_ref) + ξ·(β̇ - β̇_ref)
# 
# 代入车辆动力学方程:
# ṙ = (lf·Fyf - lr·Fyr)/Iz + Mz/Iz
# β̇ ≈ (Fyf + Fyr)/(m·Vx) - r
#
# ṡ = (lf·Fyf - lr·Fyr)/Iz + Mz/Iz - ṙ_ref
#     + ξ·[(Fyf + Fyr)/(m·Vx) - r - β̇_ref]

# 步骤3: 选择趋近律
# 最经典: ṡ = -K·sgn(s)
#   优点: 简单, 证明过稳定
#   缺点: sgn在高频切换 → 抖振 (chattering)

# 改进: ṡ = -K·sat(s/Φ)  (边界层法)
#   sat(x) = x if |x|<1 else sgn(x)
#   Φ: 边界层厚度
#   边界层内: 连续控制 → 无抖振
#   边界层外: 切换控制 → 快速趋近

# 步骤4: 得到控制律
# Mz = Mz_eq - K·sat(s/Φ)
# Mz_eq = Iz·[ṙ_ref - ξ·(β̇ - β̇_ref)]
#         - (lf·Fyf - lr·Fyr) - Iz·ξ·[(Fyf+Fyr)/(m·Vx) - r]

# 步骤5: 稳定性证明 (Lyapunov)
# V = ½·s²
# V̇ = s·ṡ = s·(-K·sgn(s) + d)  ≤ -K|s| + |s|·|d|
#                                   = -|s|·(K - |d|)
# 如果 K > |d|ₘₐₓ → V̇ < 0 → 系统渐进稳定!
# 其中d是所有不确定性的上界
```

### 2.3 抖振问题与解决方案

```
抖振 (Chattering) 的表现:
  控制信号高频振荡 → 乘客感到振动
  → 执行器(电机)频繁换向 → 磨损、发热
  → 在VMC中表现为"车子一抖一抖的"

解决方案 (从简单到复杂):

1. 边界层法 (Boundary Layer) ★最常用
   sgn(s) → sat(s/Φ)
   Φ越大 → 越平滑但跟踪精度越差
   → 需要在"平滑"和"精度"间折中

2. 高阶滑模 (Higher-order SMC)
   → 把切换放在控制量的导数上
   → 实际控制量是积分 → 天然平滑
   → 但理论更复杂

3. 自适应增益
   K不是常数, 而是根据s的大小自适应变化
   → s大时K大(快速趋近), s小时K小(减少抖振)

4. 扰动观测器 + SMC
   → 用观测器估计扰动d
   → SMC只需要对抗观测误差(远小于总扰动)
   → 需要的切换增益K显著减小 → 抖振减小
```

### 2.4 SMC vs PID vs MPC 在VMC中的对比

| 维度 | SMC | PID | MPC |
|------|-----|-----|-----|
| 鲁棒性 | ★★★★★ | ★★★ | ★★★ (需精确模型) |
| 参数调校 | ★★★ (滑模面+K) | ★★★★★ (3个参数) | ★★ (多权重矩阵) |
| 抖振 | 有 (需处理) | 无 | 无 |
| 稳态精度 | ★★★★ | ★★★★ | ★★★★★ |
| 约束处理 | 无 | 无 | 有约束优化 |
| 计算量 | ★ (很小) | ★ (最小) | ★★★★ (QP求解) |
| 实时性 | ★★★★★ | ★★★★★ | ★★★ |
| 理论门槛 | ★★★★ | ★ | ★★★★★ |

**实用建议**:
- SMC适合作为VMC的"兜底控制器" (鲁棒、快速、计算量小)
- MPC适合作为VMC的"上层优化器" (处理约束、预测优化)
- PID适合作为"简单工况的备选"
- 最佳组合: **MPC上层 + SMC下层** (MPC做优化, SMC做鲁棒跟踪)

## 3. 我的理解

1. **SMC是给"不确定的系统"设计的**：你不精确知道轮胎的侧偏刚度、路面附着系数——没关系，只要你知道这些不确定性的**上界**，SMC就能稳定工作。

2. **流体力学的类比**：
   - 滑模面 ≈ 流线/等势面（你希望流动沿着它进行）
   - 切换控制 ≈ 壁面函数（强制流动满足边界条件）
   - 抖振 ≈ 激波振荡（不连续导致的数值/物理振荡）
   - 你在CFD中处理激波的经验可以直接迁移到SMC的抖振处理！

3. **SMC的最大工程问题是抖振**：学术界有很多高阶滑模理论，但工业界最常用的还是"边界层法+自适应增益"——简单有效。

## 4. 与易三方平台的关联

- 三电机的大范围横摆力矩能力意味着SMC的切换控制有更大的执行空间
- 但高切换增益可能引起后轴两电机的快速差动 → 需要考虑差速器的疲劳/寿命
- SMC是后轴独立驱动的"天然搭档"——快速、直接、不依赖精确轮胎模型
