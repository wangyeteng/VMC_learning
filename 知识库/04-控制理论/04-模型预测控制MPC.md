# 模型预测控制 (MPC) 及其在VMC中的应用

## 1. 一句话定义
> MPC (Model Predictive Control) 是一种基于**模型预测+滚动优化+反馈校正**的先进控制方法。在VMC中，MPC能够同时处理（1）多变量耦合（纵向+侧向+横摆）、（2）执行器约束（电机扭矩上限、轮胎附着极限）、（3）未来状态预测——是VMC从"反应式控制"升级到"预测式控制"的关键技术。

## 2. 核心概念与公式

### 2.1 MPC三要素

```
1. 预测模型 (Prediction Model)
   ── 基于车辆模型预测未来Np步的状态演化
   x(k+1|k) = f(x(k|k), u(k|k))
   x(k+2|k) = f(x(k+1|k), u(k+1|k))
   ...

2. 滚动优化 (Receding Horizon Optimization)
   ── 在每个采样时刻在线求解一个有限时域最优控制问题
   min_{u(k),...,u(k+Nc-1)} Σ_{i=0}^{Np-1} ||x(k+i|k)-x_ref(k+i)||²_Q
                              + Σ_{i=0}^{Nc-1} ||u(k+i)||²_R
   s.t.  x(k+i+1|k) = f(x(k+i|k), u(k+i|k))  ← 模型约束
         x_min ≤ x ≤ x_max                     ← 状态约束
         u_min ≤ u ≤ u_max                     ← 执行器约束
   Np: 预测时域, Nc: 控制时域 (Nc ≤ Np)

3. 反馈校正 (Feedback Correction)
   ── 只执行当前时刻u(k)，下一时刻用新测量值重新优化
   这提供了对模型误差和扰动的天然鲁棒性
```

### 2.2 线性MPC的QP形式

```python
# 预测模型 (线性离散系统):
#   x(k+1) = A·x(k) + B·u(k)
#   y(k) = C·x(k)

# 将Np步预测写成紧凑形式:
#   X = Φ·x(k) + Γ·U
#   其中 X = [x(k+1); x(k+2); ...; x(k+Np)]
#        U = [u(k); u(k+1); ...; u(k+Nc-1)]

# 代价函数转换为标准QP:
#   J = Uᵀ·H·U + 2·fᵀ·U + const
#   其中 H = Γᵀ·Q̄·Γ + R̄
#        f = Γᵀ·Q̄·(Φ·x(k) - X_ref)

# 约束仍为线性: A_ineq·U ≤ b_ineq
# 这是一个标准的凸二次规划 (QP) 问题
```

> **流体力学博士的优势**: MPC本质是**有限时域的变分问题**——你把最优控制问题离散化后做滚动优化。这和你熟悉的求解偏微分方程的方法（将无限维问题离散为有限维代数问题）在数学上同构。

### 2.3 VMC中MPC的典型状态与输入

```
方案1: 基于自行车模型的MPC
  状态 x = [β, r, ψ_error, y_error]ᵀ
  输入 u = [δ (前轮转角), Mz (横摆力矩)]ᵀ
  
  优点: 简单，可实时求解
  缺点: 忽略纵向动力学、载荷转移

方案2: 基于非线性模型的MPC (NMPC)
  状态 x = [Vx, Vy, r, ψ, X, Y]ᵀ
  输入 u = [T_fl, T_fr, T_rl, T_rr, δ]ᵀ
  采用非线性车辆模型 + 非线性轮胎模型
  
  优点: 精度高，可直接优化执行器指令
  缺点: 计算量大，需要强大的求解器 (ACADO, CasADi)

方案3: 分层MPC (最实用)
  上层MPC: 车辆层面 → 输出 Fx_ref, Mz_ref (20-50Hz)
  下层QP:  扭矩分配 → 输出 T_fl..T_rr (100-200Hz)
```

### 2.4 线性时变MPC (LTV-MPC) 用于轨迹跟踪

```
核心思想: 在每个时刻，将非线性模型在当前状态附近线性化

步骤:
  1. 获取参考轨迹 {(X_ref, Y_ref, ψ_ref, V_ref)_i}
  2. 在当前状态 x(k) 处线性化车辆模型 → A_k, B_k
  3. 用线性化的 A_k, B_k 构造QP并求解
  4. 执行第一步控制 u(k)，测量新状态，回到步骤2

为什么有效: 
  - 车辆动力学在每步变化不大 → 线性化在局部是好的近似
  - 滚动优化 → 每步重新线性化 → 整体非线性行为被"分段线性"捕捉
  - 这是目前学术界和工业界最主流的方案

注意事项:
  - 纵向速度Vx变化时要重新线性化 ← 因为A矩阵依赖Vx
  - 预测时域Np不能太小 (建议 Np ≥ 10, 对应 0.5~1s)
  - 需要保证QP在每个控制周期内可解 (嵌入式求解器如qpOASES, OSQP)
```

### 2.5 MPC调参指南

| 参数 | 作用 | 建议范围 | 增大效果 |
|------|------|----------|----------|
| Np (预测时域) | 预见能力 | 10~30步 | 更优但更慢 |
| Nc (控制时域) | 控制自由度 | 2~5步 | 更灵活但更慢 |
| Q (状态权重) | 跟踪精度 | 试凑或LQR | 跟踪更紧但可能振荡 |
| R (控制权重) | 控制能量/平滑 | 试凑 | 控制更平滑但跟踪变差 |
| Ts (采样时间) | 控制带宽 | 20~100ms | 更频繁但计算负担大 |

## 3. 我的理解

1. **MPC是VMC算法升级的必经之路**：
   - 传统PID/DYC是"反应式"的——出了问题再纠正
   - MPC是"预测式"的——预知问题并提前调整
   - 对于三电机平台的多执行器协调，MPC天然适合处理多变量+多约束

2. **计算量 vs 性能的权衡**：
   - 线性MPC（QP求解）对嵌入式平台可行（~1ms求解时间）
   - 非线性MPC (NLP求解) 需要更强大的算力（~10-100ms）
   - 分层MPC是最务实的方案：上层MPC做车辆层面规划，下层QP做执行器分配

3. **流体力学中的类似思想**：
   - CFD中的"时间推进法"类似MPC的滚动时域
   - 阻力预测与形状优化中的伴随方法对偶于最优控制的伴随方程
   - 你在流体计算中的**约束优化**经验可以直接迁移

4. **MPC不是银弹**：
   - 模型不准 → 预测不准 → MPC效果打折扣
   - MPC需要准确的状态估计（β, r, Vx, Vy）→ 依赖EKF/UKF
   - 实时性始终是VMC中MPC最大的工程挑战

## 4. 与易三方平台的关联

- 三电机意味着控制输入维度更高 → MPC的优势更明显（天然处理高维）
- 后轴双电机扭矩分配可以纳入MPC的约束中
- 特殊功能（坦克转向）需要MPC的约束处理能力
- **建议路线**: 先实现线性TV-MPC → 验证 → 再探索NMPC
