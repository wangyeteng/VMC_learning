## 一、一句话理解VMC

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   VMC (Vehicle Motion Control) 的本质:                          │
│                                                                 │
│   "在保证车辆不失控的前提下，尽可能忠实地执行驾驶员的意图"         │
│                                                                 │
│   换一种说法:                                                    │
│   VMC = 一个实时求解的约束优化问题                               │
│         min   ||实际运动 - 期望运动||                            │
│         s.t.  所有轮胎不突破附着极限                             │
│               所有执行器不超出物理限制                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**为什么现在要做自研VMC？** 三个底层驱动力：

| 驱动力 | 旧范式 | 新范式 | VMC的机会 |
|--------|--------|--------|-----------|
| 电动化 | 发动机响应~100ms | 电机响应~5ms | 控制带宽提升20倍 |
| 智能化 | 人驾方向盘 | 大脑输出轨迹 | VMC需要理解"轨迹"而非"角度" |
| 构型多样化 | 前驱/后驱 单一 | 三电机/四电机 分布式 | 无现成供应商方案 |

## 二、大脑-小脑架构：30秒理解

```
                   人类神经系统                    智能汽车架构
                   ────────────                   ────────────

  大脑              "我想去北京"                   "规划一条从A到B的轨迹"
  (Cerebrum)        (意图、规划、决策)             (AD域: 感知→规划→决策)

                    ↓ 运动意图                     ↓ 目标轨迹/目标横摆/目标速度

  小脑              "协调肌肉，保持平衡"           "跟踪轨迹，保证稳定"
  (Cerebellum)      (执行、平衡、学习)             (VMC: 状态估计→力分配→执行器)

                    ↓ 神经信号                     ↓ 扭矩/制动/转向指令

  肌肉/骨骼        四肢运动                       电机/制动器/转向机
  (Actuators)      (执行动作)                     (产生车辆运动)


  ★ 关键洞察: 小脑不需要知道"为什么去北京"——它只知道"怎么让你不摔倒"
  ★ 在汽车上: VMC不需要知道"为什么选这条轨迹"——它只需要忠实地跟踪它
```

## 四、关键物理概念：一张表穷尽

| 符号 | 名称 | 物理意义 | 典型值(干燥路面) | VMC中的角色 |
|------|------|----------|------------------|------------|
| **Vx** | 纵向速度 | 车前进的速度 | 0~200 km/h | 系统矩阵的关键参数 |
| **Vy** | 侧向速度 | 车"横着滑"的速度 | 通常<1 m/s | 正常时很小，失稳时增大 |
| **β** | 质心侧偏角 | Vy/Vx, 车身指向vs速度方向的夹角 | \|β\|<2°正常, >5°危险 | **VMC最核心的被控量** |
| **r = ψ̇** | 横摆角速度 | 车绕Z轴旋转的角速度 | ±50 deg/s | 最直接的横摆运动度量 |
| **δ** | 前轮转角 | 方向盘转角/转向比 | ±30° (前轮) | 驾驶员意图的主要输入 |
| **α** | 轮胎侧偏角 | 轮胎指向vs轮胎速度方向 | \|α\|<5°线性区 | 决定侧向力大小 |
| **κ** | 滑移率 | 轮胎滚动的"打滑"程度 | 0~0.1正常 | 决定纵向力大小 |
| **μ** | 附着系数 | 路面"抓地力" | 0.8~1.0干, 0.3雪, 0.1冰 | 轮胎力上限 |
| **Fz** | 垂直载荷 | 每个轮子承担的车重 | 随弯道/制动转移 | 决定该轮可用附着力 |
| **Cf, Cr** | 侧偏刚度 | 轮胎"抵抗侧偏的能力" | -80000 N/rad | 决定操纵性(Kus) |
| **Kus** | 不足转向梯度 | >0不足, =0中性, <0过多 | 0.001~0.005 | 车辆操纵性的"基因" |
| **Mz** | 横摆力矩 | 绕Z轴旋转的力矩 | ±2000 N·m (通过扭矩差) | VMC的核心控制量 |

### 最重要的三个关系

```
1. 横摆动力学 (绕Z轴):  Iz·ṙ = lf·Fyf - lr·Fyr + Mz_add
                                      ↑                    ↑
                                 轮胎侧向力产生的         VMC通过扭矩差
                                 自然横摆力矩            注入的附加横摆力矩

2. 摩擦椭圆约束:  Fx² + Fy² ≤ (μ·Fz)²
    → 纵向力(驱动/制动)和侧向力(转向)竞争有限的附着力
    → VMC的约束优化问题就是在这个椭圆里做文章

3. 不足转向梯度:  Kus ∝ (lr/Cf - lf/Cr)
    → 前轴侧偏刚度相对越小 → 越不足转向 (推头)
    → 后轴侧偏刚度相对越小 → 越过多转向 (甩尾)
    → VMC可以通过扭矩分配"伪造"等效的侧偏刚度变化
```

## 五、VMC的核心控制回路（30秒周期）

```
     ┌──────────┐
     │ 驾驶员/大脑│  输出: 方向盘转角δ 或 目标轨迹
     └─────┬────┘
           │
           ▼
     ┌──────────┐
     │ 参考模型  │  "在这个车速和方向盘转角下，理想的车应该以多大的r转弯？"
     └─────┬────┘
           │ r_ref, β_ref
           ▼
     ┌──────────┐
     │ 比较器    │  e_r = r_actual - r_ref  (横摆角速度误差)
     │          │  e_β = β_actual - β_ref   (侧偏角误差)
     └─────┬────┘
           │ e_r, e_β
           ▼
     ┌──────────┐
     │ 上层控制器│  "需要施加多少额外横摆力矩来消除误差？"
     │ (SMC/MPC)│  输出: Mz_des (目标横摆力矩)
     └─────┬────┘
           │ Fx_des, Mz_des
           ▼
     ┌──────────┐
     │ 扭矩分配器│  "如何分配四轮扭矩来产生这个力和力矩？"
     │  (QP)    │  输出: T_fl, T_fr, T_rl, T_rr
     └─────┬────┘
           │ T_i
           ▼
     ┌──────────┐
     │ 车辆物理  │  "车实际怎么动？"
     │ (Plant)  │
     └─────┬────┘
           │ r_actual, β_actual, ay, ...
           ▼
     ┌──────────┐
     │ 状态估计器│  "从传感器测量值推断真实状态"
     │ (EKF)    │  (传感器有噪声、β无法直接测量)
     └─────┬────┘
           │
           └────────→ 反馈到比较器 (闭环!)
```

## 七、数学工具与物理概念的映射

> 作为流体力学博士，这些映射能帮你快速建立直觉

| 流体力学概念 | 车辆动力学对应 | 相似性 |
|-------------|---------------|--------|
| Navier-Stokes方程 | 车辆运动方程 (m·a = ΣF) | 都是牛顿第二定律的展开 |
| 旋转坐标系下的科氏力 (2Ω×u) | 车身坐标系下的 -r·Vy, +r·Vx 项 | 完全相同的数学结构 |
| 湍流雷诺应力张量 | 轮胎力 (Fx, Fy) 的非线性耦合 | 都有"各向异性"和"椭圆约束" |
| 湍流各向异性不变量 (Lumley三角形) | 摩擦椭圆 | 二阶张量的不变量约束 |
| 边界层分离 | 轮胎附着饱和 (η→1) | "线性区→非线性区→完全分离(失控)" |
| 涡量方程 | 横摆动力学 (Iz·ṙ = ΣMz) | 绕轴的角动量守恒 |
| CFD离散化 | 车辆模型离散化 (Euler/RK4) | ODE数值积分方法一致 |
| 变分法/伴随方法 | 最优控制 (LQR/MPC) | 目标泛函最小化 |
| 数据同化 (4D-Var/EnKF) | 卡尔曼滤波 (KF/EKF/UKF) | 贝叶斯推断 + 模型预测 + 观测修正 |
| 雷诺平均 (RANS) | 参考模型 (线性2-DOF) | 用简化模型近似复杂系统行为 |
| 大涡模拟 (LES) | 非线性MPC | 保留大尺度(车辆)动力学, 建模小尺度(轮胎) |

## 八、三电机（易三方）的特殊性

```
构型: 前轴1个电机 + 后轴2个独立电机

传统车 (前驱燃油):
  横摆力矩来源 = 方向盘转向 + ESP制动干预
  → 减速 + 横摆力矩 是耦合的

四驱电动车 (前后各1电机):
  横摆力矩来源 = 方向盘 + 前后扭矩分配 + ESP
  → 前后轴可独立控制，但左右轮仍通过差速器耦合

易三方 (前1后2):
  横摆力矩来源 = 方向盘 + 前后扭矩分配 + 后轴左右差动 + ESP
  → ★ 后轴左右可独立控制，横摆力矩与驱动力基本解耦
  → ★ 可以在不减速的情况下提供稳定横摆力矩
  → ★ 低速可实现"坦克转向" (后轮反向驱动)

关键数据:
  后轴差动能产生的最大横摆力矩:
  |Mz_max| = (2 × T_max_rear / r_w) × (tw_r / 2)
  例: T_max=200Nm, r_w=0.35m, tw_r=1.6m
  → Mz_max ≈ 200/0.35 × 1.6/2 × 2 ≈ 914 N·m

  这大概相当于什么？
  → 在20m/s时能提供约45 deg/s的横摆角速度
  → 约等于方向盘打10°所产生的自然横摆力矩
  → 也就是说: VMC可以在驾驶员不打方向的情况下，产生可观的转弯效果
```

## 十、术语速查表

| 缩写 | 全称 | 一句话 |
|------|------|--------|
| VMC | Vehicle Motion Control | 整车运动控制——本知识库的核心主题 |
| TV | Torque Vectoring | 扭矩矢量控制——左右轮扭矩不对称产生横摆力矩 |
| DYC | Direct Yaw-moment Control | 直接横摆力矩控制——TV的上层逻辑 |
| ESC/ESP | Electronic Stability Control/Program | 电子稳定程序——VMC的前身，制动干预 |
| MPC | Model Predictive Control | 模型预测控制——VMC的先进控制方法 |
| EKF/UKF | Extended/Unscented Kalman Filter | 扩展/无迹卡尔曼滤波——状态估计主力 |
| QP | Quadratic Programming | 二次规划——扭矩分配的数学框架 |
| SMC | Sliding Mode Control | 滑模控制——鲁棒性强，适合DYC |
| β | Sideslip Angle | 质心侧偏角——VMC最核心但最难度量的状态 |
| Kus | Understeer Gradient | 不足转向梯度——车辆操纵性的"基因" |
| DOF | Degree of Freedom | 自由度——2-DOF(侧向+横摆), 7-DOF(车身6DOF+4轮) |
| CoG | Center of Gravity | 质心——车辆动力学方程的参考点 |
| EEA | Electrical/Electronic Architecture | 电子电气架构——VMC的物理承载平台 |
| SOA | Service-Oriented Architecture | 面向服务的架构——软件定义汽车的基础 |
| ASIL | Automotive Safety Integrity Level | 汽车安全完整性等级——VMC通常是ASIL C/D |
| MCU | Motor Control Unit | 电机控制器——VMC扭矩指令的执行者 |
| IPB | Integrated Power Brake | 集成式助力制动——博世的线控制动 |
| EPS | Electric Power Steering | 电动助力转向 |
| ADAS/AD | Advanced Driver Assistance / Autonomous Driving | 辅助驾驶/自动驾驶——"大脑" |
