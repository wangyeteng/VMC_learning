# 直接横摆力矩控制 (DYC)

## 1. 一句话定义
> DYC (Direct Yaw-moment Control) 是通过**左右轮纵向力差异**直接产生横摆力矩来调节车辆横摆运动的方法——不依赖方向盘转角，是VMC中最基础的横摆控制手段。

## 2. 核心概念与公式

### 2.1 DYC vs 传统ESC

```
              ESC (制动干预)              DYC (驱/制动干预)
控制方式:      单轮制动                    左右轮驱/制动力差动
纵向影响:      减速（不舒服）              可加速/匀速/减速（自然）
响应速度:      快 (~50ms建压)             更快 (~5ms电机响应)
能耗:          消耗动能为热                可回收制动能量
适用范围:      稳定性紧急干预              稳定性+操控性持续优化
执行器:        ESP泵+阀                   电机+制动系统
复杂程度:      简单                        需要优化分配
```

### 2.2 DYC的横摆力矩需求计算

```
控制目标: r → r_ref (跟踪参考横摆角速度)

方法1: PID/前馈控制
  Mz_des = Iz · ṙ_ref + Kp·(r_ref - r) + Ki·∫(r_ref - r)dt + Kd·(ṙ_ref - ṙ)
  前馈项 = Iz · ṙ_ref (根据参考模型的横摆角加速度前馈)

方法2: 滑模控制 (SMC)
  定义滑模面: s = (r - r_ref) + λ·(β - β_ref)
  选择趋近律: ṡ = -K·sgn(s)
  得到: Mz_des = Iz·[ṙ_ref - λ·(β̇ - β̇_ref) - K·sgn(s)] - (lf·Fyf - lr·Fyr)

方法3: 二自由度模型逆推
  从目标状态 [β_ref, r_ref]ᵀ 反算需要的横摆力矩:
  ṙ_ref = a21·β_ref + a22·r_ref + b2·δ + Mz_des/Iz
  ⇒ Mz_des = Iz·(ṙ_ref - a21·β_ref - a22·r_ref - b2·δ)
```

### 2.3 滑模控制在DYC中的应用（详解）

```python
# 滑模控制用于DYC的完整推导

# 步骤1: 选择滑模面
# 常见选择: 
#   s = r - r_ref           (仅控制横摆角速度)
#   s = (r - r_ref) + ξ·(β - β_ref)  (联合控制横摆和侧偏角)

# 步骤2: 计算等效控制 (令 ṡ=0 在无扰动下)
#   s = r - r_ref + ξ·(β - β_ref)
#   ṡ = ṙ - ṙ_ref + ξ·(β̇ - β̇_ref)
#   代入二自由度动力学方程...

# 步骤3: 添加切换控制
#   Mz = Mz_eq - K·sat(s/Φ)  (sat代替sgn以减少抖振)
#   其中 sat(x) = x if |x|<1 else sgn(x)

# 步骤4: 稳定性证明 (Lyapunov)
#   V = 1/2·s²
#   V̇ = s·ṡ = s·(-K·sgn(s) + d)  ≤ -η|s| when K > |d|
#   其中d是有界扰动
```

### 2.4 DYC与转向的协调

```
关键矛盾: DYC和方向盘转向都会产生横摆力矩，两者可能冲突

协调策略:
  1. 优先级: 稳定性 > 驾驶员意图 > 舒适性
  2. 正常行驶: 以驾驶员转向为主, DYC做微调 (<20% 横摆力矩)
  3. 接近极限: DYC逐步介入 (20-50% 横摆力矩)
  4. 失稳边缘: DYC全力介入 (可超过50%), 同时警告驾驶员
  5. 过度干预: 驾驶员可能感到"抢方向"→ 需要良好的手感调校

加权分配:
  Mz_total = w_driver · Mz_steer + w_dyc · Mz_dyc
  其中 w 根据稳定性指标 (|β|, |Δr|) 动态调节
```

## 3. 我的理解

1. **DYC是VMC最基本也最有效的手段**：因为横摆力矩直接出现在横摆运动方程中（`Iz·ṙ = ... + Mz`），它最直接地控制横摆运动。

2. **滑模控制特别适合DYC**：
   - DYC系统有明确的模型不确定性和外部扰动（路面变化、侧风等）
   - SMC天然鲁棒 → 即使轮胎模型不准确，也能保证跟踪性能
   - 你作为流体力学博士，SMC中的Lyapunov稳定性分析对你来说应该很熟悉

3. **DYC的物理限制**：
   - 能产生的横摆力矩受限于轮距和轮胎附着力：`|Mz_max| ≈ tw·μ·Fz`
   - 低速时效果减弱（小侧偏角→小侧向力→横摆力矩主要靠差动）
   - 高附着路面效果好，冰面上几乎没有效果

4. **DYC ≠ 扭矩分配**：
   - DYC：上层，计算**需要多少横摆力矩**（一个标量Mz_des）
   - 扭矩分配：下层，计算**如何产生这个横摆力矩**（四个扭矩值）
   - 这两个层的分离是好的软件架构

## 4. 与易三方平台的关联

- 后轴双电机：左右后轮可以独立驱动/制动 → DYC的最理想硬件
- 前轴单电机：前轴无法贡献差动横摆力矩（除非加制动）
- **不对称性设计思路**：优先用后轴差动产生横摆力矩，不足时辅助前轴制动
- 三电机的一个独特优势：后轴差动时，总驱动力可以保持不变（一侧加一侧减）
