# 扭矩矢量控制 (Torque Vectoring)

## 1. 一句话定义
> 扭矩矢量控制 (TV) 是通过**左右轮驱动力/制动力的不对称分配**产生附加横摆力矩，从而主动改变车辆的横摆响应，提升操纵性和稳定性的技术。它是分布式驱动电动车VMC最核心的执行手段。

## 2. 核心概念与公式

### 2.1 差动驱动的横摆力矩产生机理

```
左右后轮驱动力不对称时产生的附加横摆力矩:

  ΔM = (Frr - Frl) · (tw/2)

  tw: 后轴轮距
  Frl, Frr: 左右后轮的纵向力

正ΔM → 逆时针横摆（左转助力）
负ΔM → 顺时针横摆（右转助力）

最大横摆力矩受限于:
  1. 电机峰值扭矩
  2. 轮胎附着极限: |Fx| ≤ √((μFz)² - Fy²)
  3. 电池充放电功率限制
```

### 2.2 TV的控制目标

```
场景1: 弯道辅助转向 (Cornering Assist)
  目标: 增加横摆角速度响应，减少不足转向
  方法: 外侧后轮增加驱动扭矩，内侧后轮减少/回收扭矩
  
场景2: 稳定性增强 (Stability Enhancement)
  目标: 抑制过多转向，防止甩尾
  方法: 外侧后轮制动/回收，内侧后轮适当驱动
  
场景3: 直线行驶稳定性
  目标: 对开路面的跑偏抑制
  方法: 高附着一侧限制扭矩，低附着一侧适度驱动

场景4: 坦克转向 (Tank Turn)
  目标: 极小半径转弯/原地掉头
  方法: 左右后轮反向驱动（一侧正转一侧反转）
```

### 2.4 TV+扭矩分配的优化框架

```
标准的扭矩分配问题 (Control Allocation):

决策变量: u = [T_fl, T_fr, T_rl, T_rr]ᵀ

目标函数: J(u) = ||Bu - v_des||²_W  +  λ·||u||²
  Bu:  执行器产生的总纵向力Fx_total和横摆力矩Mz_total
  v_des = [Fx_des, Mz_des]ᵀ: 上层控制器输出的目标力/力矩

约束条件:
  1. T_min ≤ u_i ≤ T_max  (电机/制动器物理限制)
  2. |u_i| ≤ r_w · √((μ_i·Fz_i)² - Fy_i²)  (轮胎附着限制)
  3. ΣP_i ≤ P_bat_max  (电池功率限制)
  4. Ση_i·u_i = 0 (制动能量回收效率约束, 可选)

这是典型的二次规划 (QP) 问题！
```

### 2.5 TV效果的评价指标

```
1. 横摆角速度跟踪误差: e_r = r_actual - r_ref
2. 质心侧偏角抑制: |β| < β_threshold
3. 转向盘力矩(手感): 驾驶员感受到的反馈力变化
4. 侧向加速度响应: ay达到目标值的延迟
5. 能量效率: TV带来的额外能耗 vs 稳定性收益
```

## 3. 我的理解

1. **TV本质上就是一个横摆力矩注入器**：传统车通过制动（ESP）来产生横摆力矩（减速→不舒服），电动车通过驱动扭矩分配来产生（不减速→更自然）。这是电动化给VMC带来的最大红利。

2. **扭矩分配是"带约束的资源分配问题"**：
   - 资源：各轮可用的附着力"预算" (μFz)
   - 需求：总驱动力Fx_total + 横摆力矩Mz_total
   - 这就是为什么QP框架如此适合——天然处理约束下的最优分配

3. **与ESP的关键区别**：
   - ESP = 单轮制动干预 = 减速+横摆力矩（耦合的）
   - TV = 驱动/制动的左右差动 = 横摆力矩独立可控（解耦的）
   - 这意味着TV可以在**不减速甚至加速的情况下**提供稳定性

4. **流体力学的类比**：TV就像船用推进器的差动推力——左桨和右桨推力的差异产生偏航力矩。完全相同的物理原理。

## 4. 与易三方平台的关联

- **后轴双电机独立驱动是TV的理想硬件平台**
- 前轴单电机 + 后轴双电机意味着：
  - 后轴TV能力充足（可独立控制左右后轮扭矩）
  - 前轴无TV能力（需要通过制动或转向来补偿）
- 三电机比四电机少一个执行器，但在TV方面**后轴的独立控制已足够满足大多数工况**
- 需要研究：在某些极限工况下，前轴无TV能力是否构成瓶颈？
