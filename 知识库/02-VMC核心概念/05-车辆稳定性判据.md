# 车辆稳定性判据 — β-β̇ 相平面与稳定域

## 1. 一句话定义
> 车辆稳定性判据（尤其是 β-β̇ 相平面分析）是判断车辆是否"可控"的数学边界——它在 β（质心侧偏角）- β̇（质心侧偏角速度）平面上画出一个"安全区"，一旦状态轨迹超出安全区边界，车辆将进入不可控的失稳状态。

## 2. 核心概念与公式

### 2.1 相平面分析的基本思想

```
相平面的核心思想:
  将车辆的"横向状态"抽象为二维空间中的一个点 (β, β̇)
  研究这个点在各种输入下如何运动

  β̇ ↑
     │    *  ← 失稳轨迹 (发散)
     │  /
     │ /      ┌──────────┐
     │/       │  稳定域  │  ← VMC的目标: 保持状态在这个区域内
  ───┼───────┤ (Stable  │──────→ β
     │        │  Region) │
     │        └──────────┘
     │  从任何初始点出发,
     │  如果轨迹收敛到原点 → 稳定
     │  如果轨迹发散 → 失稳
```

### 2.2 β-β̇ 相平面的稳定域边界

稳定域边界由两个物理因素决定:

**边界1: 轮胎附着极限 (主要约束)**

当后轴轮胎侧向力饱和 (|αr|过大) 时, 系统失去稳定性。边界近似为:

```
|β + lr·r/Vx| > αr_sat  →  不稳定

其中 αr_sat ≈ arctan(3·μ·g·m·lf/(Cr·L))
(后轴最大侧偏角, 通常 5°~10° 干燥路面)

在相平面上:
  β̇_max = ±(μg/Vx) · sign(需要保持稳定的方向)
```

**边界2: 控制输入饱和**

方向盘转角有限、电机扭矩有限 → 控制器能做的最多就是在一定范围内"推"状态回到稳定域。

### 2.3 稳定域的计算方法

```python
# 稳定域边界可以用以下方法求解:

# 方法1: 二自由度模型的相平面分析
# 在给定Vx, δ=0, 不同初始条件(β0, β̇0)下,
# 仿真系统的自由响应, 看哪些初始点收敛、哪些发散

# 方法2: 解析边界 (基于轮胎饱和条件)
# 当 |αr| = αr_sat 时, 后轴侧向力达到最大
# 这发生在: |β - lr·r/Vx| = αr_sat
# 代入 r = β̇ + (Cf+Cr)·β/(m·Vx) + ...

# 方法3: 李雅普诺夫直接法
# 构造V(β, β̇) > 0, 若在某个域内 V̇ < 0 → 该域是稳定的
```

### 2.4 稳定域的关键特征量

```
1. 原点稳定性 (β=0, β̇=0):
   原点是稳定平衡点 (Vx低于临界车速时)

2. 稳定域宽度 (在β̇=0处):
   能容忍的最大侧偏角 |β_max_stable|
   干燥路面: ≈ 3°~6°
   冰雪路面: ≈ 1°~2°
   → 低附路面稳定域显著缩小

3. "鞍点" (存在过多转向时):
   原点附近出现鞍点结构 → 某个方向的扰动会导致发散
   Vx > Vcrit 时发生

4. 吸引域形状:
   不足转向: 椭圆/肾形, 覆盖范围大
   过多转向: 狭窄的带状, Vx越高越窄
```

### 2.5 稳定域随参数的变化

```
纵向速度Vx的影响:
  Vx ↑ → 稳定域缩小
  → 高速行驶时的稳定裕度更小
  → VMC在高速时需要更早介入

路面附着系数μ的影响:  
  μ ↓ → 稳定域急剧缩小
  → 冰雪路面几乎随时可能失稳
  → VMC的干预阈值应随μ降低而降低

转向输入δ的影响:
  δ ↑ → 稳定域偏移/变形
  → 弯道行驶时稳定域不对称
  → 一侧的稳定裕度显著小于另一侧
```

## 3. 我的理解

1. **β-β̇相平面是VMC稳定控制的理论基础**：
   - 不仅要知道当前β是多少（状态估计的任务）
   - 还要知道当前离稳定域边界有多远（这是VMC何时介入的判断依据）
   - 如果(β, β̇)接近边界 → VMC必须强力介入
   - 如果(β, β̇)远离边界 → VMC可以做更温和的操控优化

2. **流体力学类比**：
   - β-β̇相平面 ≈ 流动稳定性的相图 (如Rayleigh-Bénard对流的分叉图)
   - 稳定域 ≈ 层流稳定区
   - 边界 ≈ 临界Reynolds数
   - 失稳 ≈ 湍流转换
   - 你研究过的分叉/稳定性理论这里完全适用！

3. **为什么β̇也很重要**：
   - β大但β̇小 → 车在"漂移"但稳定 → 驾驶员有时间反应
   - β不大但β̇大 → 车在"快速滑出" → 极其危险
   - 理想VMC应同时监控 β 和 β̇

## 4. 与易三方平台的关联

- 三电机的大范围横摆力矩注入能力意味着可以"推"回更大的β偏离
- 但后轴差动也改变了β的动力学（相当于在β̇方程中加入项）
- 需要为三电机平台重新计算稳定域边界
- 坦克转向等特殊模式下的β-β̇行为需要专门分析
