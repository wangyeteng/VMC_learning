# VMC定义、演进与系统边界

## 1. 一句话定义
> **VMC (Vehicle Motion Control)** 是负责车辆纵向、侧向、垂向三个方向运动控制的软件功能集合。它接收来自"大脑"（AD域控制器）的运动意图（目标轨迹/目标速度/目标横摆），通过协调驱动、制动、转向、悬架等多执行器，在保证稳定性的前提下实现期望的车辆运动。

## 2. 核心概念与公式

### 2.1 VMC概念的演进

```
ESP (1995)  →  IVD (2000)  →  VDC (2005)  →  VMC (2015)  →  智能VMC (2022+)
   |              |              |              |                |
仅制动干预     制动+发动机    加入转向控制   多执行器协调    大脑-小脑解耦
(Bosch)       扭矩控制       (主动转向)    (线控底盘)      + AI/ML引入
```

**演进的核心逻辑**:
1. 执行器种类增多 → 从"制动"到"驱动/制动/转向/悬架"
2. 电动化 → 电机响应比发动机快100倍 → 控制带宽大幅提升
3. 智能化 → 大脑给出的是"轨迹"而非"方向盘角度" → 小脑需要做更多解算
4. 线控化 → 方向盘/制动踏板与执行器解耦 → VMC成为唯一的协调中心

### 2.2 VMC的功能层级（自底向上）

```
┌──────────────────────────────────────────┐
│  第4层: 运动规划接口 (Motion Request)     │ ← 接收大脑指令
├──────────────────────────────────────────┤
│  第3层: 车辆状态观测与参考模型             │ ← β, r, Vx, μ在线估计
├──────────────────────────────────────────┤
│  第2层: 目标力/力矩计算                   │ ← 需要多少Fx_f/r, ΔM
│          (纵向力、侧向力、横摆力矩)        │
├──────────────────────────────────────────┤
│  第1层: 执行器分配与控制                  │ ← 扭矩/制动/转向/悬架指令
│          (Actuator Allocation & Control)  │
└──────────────────────────────────────────┘
```

### 2.3 VMC的输入输出接口定义

```
输入 (来自"大脑"或驾驶员):
────────────────────────────
  - 目标轨迹 (X_ref, Y_ref, ψ_ref) 或
  - 目标车速 Vx_ref
  - 目标横摆角速度 r_ref (可由方向盘转角映射)
  - 目标加速度 ax_ref, ay_ref
  - 驾驶模式 (ECO/Normal/Sport/Off-road)
  - 路面附着系数估计 μ

输入 (来自传感器):
────────────────────────────
  - 轮速 (4个)
  - 方向盘转角 δ
  - 横摆角速度 r (IMU)
  - 纵向/侧向加速度 ax, ay (IMU)
  - 各轮扭矩/制动压力反馈
  - 悬架行程 (如有空气悬架/CDC)
  - GPS/RTK位置与航向 (如有)

输出 (发给执行器):
────────────────────────────
  - 各轮驱动力矩指令 (Tm_fl, Tm_fr, Tm_rl, Tm_rr)
  - 各轮制动压力指令 (Pb_fl, ...)
  - 前轮/后轮转向角指令 (如有主动转向)
  - 悬架阻尼/刚度指令 (如有主动悬架)
  - 限滑差速器锁止指令 (如有)
```

### 2.4 VMC与周边系统的关系

```
           ┌──────────────┐
           │  ADAS/AD域   │ ← "大脑": 感知, 预测, 规划, 决策
           │  (大脑)      │
           └──────┬───────┘
                  │ 目标轨迹/目标速度/目标横摆
                  │ (CAN/FlexRay/Ethernet)
                  ↓
           ┌──────────────┐
           │   VMC (小脑) │ ← 本系统: 运动控制, 稳定性保证
           └──────┬───────┘
                  │ 扭矩/制动/转向/悬架指令
        ┌─────────┼─────────┐
        ↓         ↓         ↓
   ┌────────┐┌────────┐┌────────┐
   │驱动域  ││制动域  ││转向域  │ ← 执行器控制器
   │(MCU)   ││(IPB)   ││(EPS)   │
   └────────┘└────────┘└────────┘

关键约束:
  - 大脑→小脑: 延迟 < 20-50ms (ADAS场景)
  - 小脑→执行器: 延迟 < 5-10ms (稳定性控制)
  - VMC控制周期: 通常 5-10ms
```

## 3. 我的理解

1. **VMC的本质是"约束优化问题"**：
   - 目标: 尽可能满足大脑/驾驶员的运动意图
   - 约束: 同时保证所有轮胎不饱和 (η < 1)、车辆在稳定域内
   - 方法: 在有约束的条件下分配各执行器的出力

2. **"小脑"这个比喻非常精准**：人类小脑负责（1）协调肌肉运动、（2）保持身体平衡、（3）运动学习——这正是VMC的三大核心功能。

3. **VMC是整车控制的核心调度者**，不是某一个控制器。它不直接驱动电机——它计算**每个电机应该出多少力**，然后发给MCU去执行。

4. **自研VMC的核心壁垒**（为什么不能直接用博世的？）：
   - 轮胎模型参数是各主机厂的核心资产（需要大量测试标定）
   - 车辆动力学特性（质心、惯量、悬架特性）不同
   - 差异化驾驶体验需要定制化的控制策略
   - 三电机/四电机等非传统构型没有现成方案

## 4. 与易三方平台的关联

- 易三方是**三电机分布式驱动**，意味着后轴左右轮可以独立控制扭矩
- 这为VMC的第1层（执行器分配）提供了比传统车大得多的自由度
- 但也引入了新的约束：电机发热、电池功率限制、单电机失效等
- **差异化机会**：利用三电机的冗余性和不对称性，实现传统VMC做不到的功能
