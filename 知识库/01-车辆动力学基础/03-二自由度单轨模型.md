# 二自由度单轨模型 (Bicycle Model)

## 1. 一句话定义
> 二自由度（侧向Vy + 横摆r）单轨模型是车辆横向动力学最简化的数学描述，将左右轮合并为一个"等效轮"，忽略侧倾和俯仰运动，是**VMC参考模型设计的起点**。

## 2. 核心概念与公式

### 2.1 模型假设

```
1. 左右轮合并 → "自行车"模型 (Bicycle)
2. 纵向速度Vx恒定 (忽略纵向动力学)
3. 小角度假设: sin(θ)≈θ, cos(θ)≈1
4. 轮胎侧向力与侧偏角成线性关系: Fy = Cα·α
5. 忽略侧倾、俯仰、载荷转移
6. 忽略空气动力学效应
```

### 2.2 状态空间方程推导

**状态变量**: x = [Vy, r]ᵀ  (或等价地用 [β, r]ᵀ)
**输入**: u = δ (前轮转角)

```
前后轮侧偏角:
  αf = δ - arctan((Vy + lf·r)/Vx) ≈ δ - (Vy + lf·r)/Vx
  αr = -arctan((Vy - lr·r)/Vx) ≈ -(Vy - lr·r)/Vx

前后轮侧向力 (线性轮胎假设):
  Fyf = Cf·αf = Cf·[δ - (Vy + lf·r)/Vx]
  Fyr = Cr·αr = Cr·[-(Vy - lr·r)/Vx] = Cr·(lr·r - Vy)/Vx

侧向力平衡方程:  m·(dVy/dt + r·Vx) = Fyf + Fyr
横摆力矩平衡方程:  Iz·dr/dt = lf·Fyf - lr·Fyr
```

### 2.3 标准状态空间形式

```
[dβ/dt]   [a11  a12] [β]   [b1]
[      ] = [        ] [ ] + [  ] · δ
[dr/dt ]   [a21  a22] [r]   [b2]

其中 (用β=Vy/Vx替代Vy):
  a11 = -(Cf+Cr)/(m·Vx)
  a12 = -1 - (lf·Cf - lr·Cr)/(m·Vx²)
  a21 = -(lf·Cf - lr·Cr)/Iz
  a22 = -(lf²·Cf + lr²·Cr)/(Iz·Vx)

  b1 = Cf/(m·Vx)
  b2 = lf·Cf/Iz

m:  整车质量
Iz: 绕Z轴转动惯量
lf: 质心到前轴距离
lr: 质心到后轴距离
Cf: 前轴等效侧偏刚度 (2×单轮侧偏刚度)
Cr: 后轴等效侧偏刚度
Vx: 纵向速度
```

### 2.4 稳态响应与不足转向梯度

```
稳态横摆角速度增益:
  r/δ|_ss = Vx / (L + Kus·Vx²)

其中 Kus = (m/L)·(lr/Cf - lf/Cr)  ← 不足转向梯度！

Kus > 0: 不足转向 (Understeer) —— 大多数量产车
Kus = 0: 中性转向 (Neutral steer)
Kus < 0: 过多转向 (Oversteer) —— 不稳定！

特征车速 (不足转向时):
  Vchar = √(L/Kus)  ← 横摆增益最大的车速

临界车速 (过多转向时):
  Vcrit = √(L/|Kus|)  ← 超过此车速车辆不稳定！
```

### 2.5 频率响应

```python
# 从传递函数 G(s) = r(s)/δ(s) 分析
# 这是典型的二阶系统

特征方程:
  det(sI - A) = s² - (a11+a22)s + (a11·a22 - a12·a21) = 0

固有频率 ωn 和阻尼比 ζ:
  ωn² = a11·a22 - a12·a21
  2ζωn = -(a11 + a22)
```

> **流体力学类比**: 车辆的二自由度横向动力学 ≈ **带阻尼的弹簧-质量系统**（二阶系统）。侧偏刚度Cf/Cr提供"弹簧力"，轮胎侧偏的迟滞提供"阻尼"。这个类比非常精确——固有频率、阻尼比等概念完全通用。

## 3. 我的理解

1. **这是VMC参考模型的核心**：VMC控制器通常先由这个简化模型计算出"理想的r和β"，再通过扭矩分配使实际值趋近理想值。

2. **不足转向梯度Kus是车辆操纵性的"基因"**：
   - Kus由前后侧偏刚度的相对大小决定 → 调整前后悬架/轮胎/胎压可改变Kus
   - 量产车故意设计为微不足转向（Kus > 0），因为过多转向对普通驾驶者来说太危险
   - VMC可以通过主动扭矩分配**人工改变等效Kus**

3. **车速Vx是关键参数**：
   - 注意状态矩阵A的每个元素都含Vx → 这是一个**参数依赖系统**（LPV系统）
   - 高速时系统动态变化剧烈（横摆阻尼减小），对控制器的实时性要求更高

4. **局限性**：
   - 线性轮胎假设在 |α| > 4~5° 时失效 → 大侧偏角工况需要非线性处理
   - 忽略载荷转移 → 弯道制动/加速时误差很大
   - 恒定Vx假设 → 需要与纵向动力学解耦或扩展

## 4. 与易三方平台的关联

- **后轮独立驱动 = 可以直接注入横摆力矩**，相当于在横摆方程右侧加一项 ΔM/Iz
- `Iz·dr/dt = lf·Fyf - lr·Fyr + ΔM` ← 这ΔM就是VMC通过扭矩分配产生的
- 三电机意味着一侧后轮可以驱动、另一侧可以制动 → ΔM的调节范围很大
- 低速时的坦克转向本质：利用差速产生极大ΔM，使车辆绕自身中心旋转
