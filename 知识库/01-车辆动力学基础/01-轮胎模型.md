# 轮胎模型

## 1. 一句话定义
> 轮胎模型是描述轮胎与路面之间作用力（纵向力Fx、侧向力Fy、回正力矩Mz）与轮胎运动状态（滑移率κ、侧偏角α、外倾角γ、垂直载荷Fz）之间函数关系的数学模型。**它是车辆动力学仿真的根基，VMC控制精度的上限由轮胎模型的准确性决定。**

## 2. 核心概念与公式

### 2.1 轮胎坐标系 (SAE标准)

```
         Fx (纵向力, 驱动为正)
         ↑
         |
    ←----+---- 轮胎行驶方向
         |
         ↓
         Fy (侧向力)

    α: 侧偏角 = arctan(Vy/Vx)  ← 轮胎速度方向与轮胎指向的夹角
    κ: 滑移率 = (ωR - Vx)/max(ωR, Vx)  ← 驱动时; 制动时 = (Vx - ωR)/Vx
    γ: 外倾角 ← 轮胎平面与垂直面的夹角
```

### 2.2 摩擦椭圆 (Friction Ellipse)

**物理直觉**: 轮胎能提供的总附着力有限，纵向力和侧向力之间存在耦合——像一块"披萨"只能切分成两片。

```
    Fy ↑
       |   *  *  *
       | *      *
       |*   ○    *    ← 椭圆内任意点可达到
       | *      *
       |   *  *  *
       +-------------→ Fx

    Fx²/Fx_max² + Fy²/Fy_max² ≤ 1
```


### 2.3 Magic Formula (Pacejka 2002)

经典半经验轮胎模型的核心公式：

```
y(x) = D·sin(C·arctan(B·x - E·(B·x - arctan(B·x))))

其中:
  Y(X) = y(x) + Sv        ← 加入垂直偏移
  x = X + Sh               ← 加入水平偏移

  B: 刚度因子 (Stiffness factor)
  C: 形状因子 (Shape factor) 
  D: 峰值因子 (Peak factor) → D·C·B 正比于拐点斜率
  E: 曲率因子 (Curvature factor)
  Sh: 水平偏移 (Horizontal shift) — 表征轮胎的帘布层转向效应
  Sv: 垂直偏移 (Vertical shift) — 表征轮胎的锥度效应

典型参数 (乘用车轮胎):
  纯侧偏: C ≈ 1.3,  B ≈ 6~15,  E ≈ -1~1
  纯纵滑: C ≈ 1.6,  B ≈ 5~12,  E ≈ 0.5~1
```

### 2.4 核心概念: 侧偏刚度 (Cornering Stiffness)

```
Cα = ∂Fy/∂α |_{α=0}  = B·C·D    (单位: N/rad)

这是VMC控制中最关键的轮胎参数！
→ 它决定了车辆对方向盘输入的响应快慢
→ 不足转向梯度与前后轴侧偏刚度的相对大小直接相关
→ 随载荷、胎压、路面附着系数变化
```

### 2.5 附着系数利用率

```
η = √(Fx² + Fy²) / (μ·Fz)   ∈ [0, 1]

VMC的一个核心目标: 保持每次轮胎的 η < 1 (不饱和)
当 η → 1 时，车辆接近失稳
```

## 3. 我的理解

1. **轮胎是车辆和路面唯一的连接**——再好的控制器，如果对轮胎力的估计错了，控制效果一定差。这就是为什么VMC需要准确的状态估计（估计轮胎力、侧偏角等）。

2. **Magic Formula 本质是高维非线性函数拟合**——它用三角函数族去逼近轮胎实验数据的S形曲线。不要过度神化它，任何光滑的S形曲线都可以用类似方法拟合。

3. **摩擦椭圆是最重要的物理直觉**：
   - 刹车时（需要Fx），侧向力能力下降（Fy_max变小）→ 这就是为什么弯中急刹容易甩尾
   - 驱动时同理，大油门出弯前轮侧向力不足→ 推头
   - VMC的核心思路就是：**合理分配各轮的Fx（驱动/制动力），使得每轮的(Fx, Fy)不越界**

4. **与流体力学的类比可以帮助记忆**：
   - 摩擦椭圆 ≈ 湍流各向异性不变量图
   - 轮胎滑移率 ≈ 多孔介质的达西流动 —— 都有"驱动力越大，实际流速/滑移越偏离线性"的非线性关系
   - Pacejka模型 ≈ 翼型的升力系数曲线 —— 都是先线性增长，达到峰值后下降（失速/饱和）

## 4. 与易三方平台的关联

- 三电机分布式驱动意味着**后轴左右轮可以独立控制驱动力矩**，这为扭矩矢量控制提供了硬件基础
- 需要特别注意: 三个电机（可能是前轴中央电机+后轴双轮毂/轮边电机）的扭矩分配在不同路面附着系数下的轮胎力耦合
- 后轮独立驱动时，差动产生的横摆力矩与轮胎的侧偏特性密切相关
- **侧偏刚度的在线辨识**对VMC自适应控制很重要（磨损、胎压、温度都会改变侧偏刚度）
