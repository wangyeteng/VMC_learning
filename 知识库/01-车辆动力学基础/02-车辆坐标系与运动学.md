# 车辆坐标系与运动学

## 1. 一句话定义
> 车辆坐标系是描述车辆空间运动（位置、姿态、速度、加速度）的基准框架，是建立车辆动力学方程的语言基础。

## 2. 核心概念与公式

### 2.1 车辆坐标系定义 (ISO 8855 / SAE J670)

```
            X (纵向, 前进方向为正)
            ↑
            |
            |   横摆角速度 r = ψ̇ (绕Z轴)
            |       ↑
    ←-------+------→ Y (侧向, 向左为正)
            |
            ↓
            Z (垂向, 向上为正)

    俯仰角速度 q = θ̇ (绕Y轴)
    侧倾角速度 p = φ̇ (绕X轴)

    整车6个自由度:
    平动: 纵向Vx, 侧向Vy, 垂向Vz
    转动: 侧倾(roll), 俯仰(pitch), 横摆(yaw)

    车身坐标系原点: 通常取车辆质心(CoG)
```

### 2.2 关键角度定义

```
质心侧偏角 β = arctan(Vy/Vx) ≈ Vy/Vx (小角度时)
  物理意义: 车辆速度方向与车身纵向的夹角
  正常行驶: |β| < 2° (干燥路面)
  极限工况: |β| 可能达到 5~15°
  失稳标志: |β| 迅速增大，|β̇| 也增大

横摆角 ψ: 车身纵轴与世界坐标系X轴的夹角
横摆角速度 r = ψ̇: 车辆绕Z轴的旋转速率

前轮转角 δ: 前轮相对于车身纵轴的转角
侧偏角 αf, αr: 前后轮速度方向与轮胎指向的夹角
```

### 2.3 运动学关系（世界坐标系 ↔ 车身坐标系）

```
世界坐标系下车辆位置:
  Ẋ = Vx·cos(ψ) - Vy·sin(ψ)
  Ẏ = Vx·sin(ψ) + Vy·cos(ψ)
  ψ̇ = r

其中 Vx, Vy 是车身坐标系下的速度分量
注意: 即使在车身坐标系下，车辆也未必"指向速度方向"
      车身指向 = ψ; 速度方向 = ψ + β
```

### 2.4 阿克曼转向几何 (Ackermann Steering)

```
理想的转向几何（低速、无侧偏）:
  cot(δo) - cot(δi) = tw / L

  δo: 外前轮转角
  δi: 内前轮转角  
  tw: 主销间距 (Kingpin width)
  L:  轴距

  实际车辆常用"平均前轮转角" δ = (δo + δi)/2

  纯滚动条件下的转向半径:
  R = L / tan(δ)  ← 低速理论值
  
  考虑侧偏后的转向半径:
  R = L / (tan(δ) + tan(αr - αf))  ← 实际
```

### 2.5 加速度在车身坐标系下的表达

```python
# 这一组公式很容易搞混，需要特别注意！

ax = dVx/dt - r·Vy   # 纵向加速度 (含科氏力项!)
ay = dVy/dt + r·Vx   # 侧向加速度 (含科氏力项!)

# 在稳态圆周行驶时:
# dVx/dt = 0, dVy/dt = 0
# ax = -r·Vy  (向心加速度的纵向分量，通常很小)
# ay =  r·Vx  (向心加速度的主要分量 ≈ Vx²/R)
```

> **流体力学博士的直觉**: 这正是**旋转参考系下的Navier-Stokes方程**中的科氏力项！你在旋转坐标系（车身）下写运动方程，必然出现 `r × V` 的科氏加速度项。流体中的涡量方程和这里本质相同。

## 3. 我的理解

1. **β 是VMC中最重要但也最难获取的变量之一**：
   - 它直接反映车辆是否"推头"或"甩尾"
   - 没有廉价传感器可以直接测量β → 必须通过状态估计获取
   - β 的准确估计是区分"好的VMC"和"基本VMC"的关键指标

2. **旋转坐标系下的惯性力项是新手最容易出错的地方**：
   - 写运动方程时必须记得 `r×Vy` 和 `-r×Vx` 这些耦合项
   - 类似的错误在流体计算中也很常见——忘记旋转坐标系下的附加项

3. **不足转向 vs 过多转向**本质上由前后轴侧偏角的相对大小决定：
   - `αf > αr` → 不足转向 (前轮先于后轮偏离行驶线)
   - `αf < αr` → 过多转向 (后轮先于前轮偏离，尾部外甩)
   - `αf = αr` → 中性转向

## 4. 与易三方平台的关联

- 三电机平台的**后轮独立驱动**可以为横摆角速度r提供独立于方向盘的控制通道
- 低速时可通过后轮差速实现"坦克转向"——减少转弯半径
- 需要精确的质心估计（CoG随乘员和货物变化）来提高β估计精度
