# 卡尔曼滤波基础

## 1. 一句话定义
> 卡尔曼滤波 (Kalman Filter) 是一种**递归的最优状态估计器**：它结合"模型预测"和"传感器观测"，在两者都有噪声的情况下，给出状态的最优估计（最小均方误差意义下）。在VMC中，它的核心任务是**从有噪声的传感器中还原出车辆的真实状态**——尤其是β（质心侧偏角），因为这个量没有廉价传感器可以直接测量。

## 2. 核心概念与公式

### 2.1 问题设定

```
我们有一个系统:
  x(k+1) = A·x(k) + B·u(k) + w(k)    ← 过程方程 (模型预测)
  y(k)   = C·x(k) + v(k)              ← 观测方程 (传感器测量)

  x: 状态向量 (我们想知道的, 如 β, r, Vy)
  u: 控制输入 (我们能控制的, 如 δ, Mz)
  y: 观测向量 (我们能量到的, 如 r_IMU, ay_IMU)
  w: 过程噪声 ~ N(0, Q)  ← 模型不准导致的误差
  v: 观测噪声 ~ N(0, R)  ← 传感器噪声

目标: 给定 y(1),...,y(k), 估计 x(k) 的最优值
```

### 2.2 KF的两步循环

```
步骤1: 预测 (Time Update / Predict)
─────────────────────────────────────
  用模型预测下一刻的状态:

  x̂⁻(k) = A·x̂(k-1) + B·u(k-1)         ← 先验估计 (预测值)
  P⁻(k) = A·P(k-1)·Aᵀ + Q             ← 先验协方差 (预测的不确定性)

  "根据我知道的物理规律, 车应该到这儿了...
   但我不太确定, 大概±这么多"


步骤2: 更新 (Measurement Update / Correct)
─────────────────────────────────────────
  用传感器测量修正预测:

  K(k) = P⁻(k)·Cᵀ·(C·P⁻(k)·Cᵀ + R)⁻¹   ← 卡尔曼增益

  x̂(k) = x̂⁻(k) + K(k)·(y(k) - C·x̂⁻(k))  ← 后验估计
  P(k) = (I - K(k)·C)·P⁻(k)              ← 后验协方差

  "传感器说我在那儿, 考虑到传感器的噪声...
   那我最可能在两者之间的这个位置"


卡尔曼增益K的物理直觉:
  ┌─────────────────────────────────────────────┐
  │ 如果传感器很准 (R小)  →  K大 → 更相信传感器 │
  │ 如果传感器很烂 (R大)  →  K小 → 更相信模型   │
  │ 如果预测不确定 (P⁻大) →  K大 → 需要传感器校正│
  │ 如果预测很确定 (P⁻小) →  K小 → 传感器影响小 │
  └─────────────────────────────────────────────┘
```

### 2.3 在VMC中：状态与观测的对应

```python
# 典型的VMC KF设置

状态 x = [β, r, Vy]ᵀ  (或 [Vy, r]ᵀ 在2-DOF简化中)

控制输入 u = [δ, ax]ᵀ

观测 y = [r_IMU, ay_IMU]ᵀ  ← 这些是IMU直接测量的

# 关键问题: 没有直接测量β的传感器!
# → β必须通过模型推断 + 其他测量的间接约束来估计
# → 这就是为什么需要KF —— 它天然擅长处理"不可直接观测但可通过模型推断"的状态

# C矩阵 (观测方程):
# y[0] = r = 0·β + 1·r + 0·Vy  → C的第1行 = [0, 1, 0]
# y[1] = ay = Vx·(β̇+r) ≈ ...   → 与β和r都有关, 间接约束

# 可观性分析:
# 如果系统是可观的 → KF可以从r和ay的测量中推断出β
# 但可观性随工况变化——某些工况下β可能不可观
```

### 2.4 KF在VMC中的实际挑战

```
挑战1: 系统是非线性的!
  轮胎力Fy(α)是非线性的 → A矩阵实际上依赖于状态
  → 线性KF不够用 → 需要EKF或UKF

挑战2: Vx是变化的参数
  A矩阵的每个元素都含Vx → Vx变化时A也在变
  → 需要使用LTV-KF (线性时变KF)

挑战3: 需要准确的过程噪声Q
  Q建模了"我们对模型的信任程度"
  Q太小 → KF过于相信模型 → 估计跟不上真实状态
  Q太大 → KF过于相信传感器 → 估计噪声大
  → Q的调校是KF在实际中最大的工程挑战

挑战4: 传感器偏差 (bias)
  IMU的横摆角速度测量常常有缓慢漂移的bias
  → 需要将bias也纳入状态估计: x_extended = [β, r, Vy, bias_r]ᵀ

挑战5: 可观性退化
  在某些工况下β变得不可观 (如直行时,Vy≈0, 没有侧向激励)
  → KF的β协方差会变大但估计不会发散
  → 需要额外的激励 (轻微的转向) 或额外的传感器 (GPS)
```

### 2.5 简化的KF伪代码

```python
class KalmanFilter:
    """线性KF, 用于VMC状态估计"""
    
    def __init__(self, A, B, C, Q, R, x0, P0):
        self.A, self.B, self.C = A, B, C
        self.Q, self.R = Q, R
        self.x = x0  # 状态估计
        self.P = P0  # 协方差
    
    def predict(self, u, dt):
        """预测步骤: 用模型推演状态"""
        # 离散化A (或直接用离散A)
        self.x = self.A @ self.x + self.B @ u
        self.P = self.A @ self.P @ self.A.T + self.Q
    
    def update(self, y):
        """更新步骤: 用测量修正状态"""
        # 卡尔曼增益
        S = self.C @ self.P @ self.C.T + self.R   # 新息协方差
        K = self.P @ self.C.T @ np.linalg.inv(S)
        
        # 新息 (Innovation)
        y_pred = self.C @ self.x
        innovation = y - y_pred
        
        # 修正
        self.x = self.x + K @ innovation
        self.P = (np.eye(len(self.x)) - K @ self.C) @ self.P
```

> **流体力学博士的直觉**: KF本质上就是**数据同化中的最优插值** (Optimal Interpolation) — 你把模型预报和观测值用各自的误差协方差加权组合。如果你做过4D-Var或集合卡尔曼滤波（EnKF），这里完全一样，只是KF是递归的（序贯的）而4D-Var是批处理的。

## 3. 我的理解

1. **KF在VMC中的角色是"虚拟传感器"**：它创造出了β这个没有物理传感器能直接测量的关键状态量。没有KF（或EKF/UKF），VMC就是在"盲飞"。

2. **KF = 模型 + 测量 + 不确定性管理**：它不是魔术——它只是把我们本来就有的两样东西（物理模型和传感器数据）用最优的方式组合起来。如果模型很烂，KF的输出也很烂。

3. **参数调校 (Q, R) 是艺术也是科学**：
   - Q和R决定了KF的信赖程度
   - 实际中通过传感器噪声测试确定R
   - Q通过试凑或自适应方法确定
   - 一个好的初始Q/R猜测可以通过Allan方差分析（IMU噪声特性）获得

## 4. 与易三方平台的关联

- 三电机平台对β估计的精度要求更高（因为扭矩分配依赖准确的轮胎力估计→依赖准确的α→依赖准确的β）
- 后轴独立驱动的横摆力矩注入可以作为KF的"激励信号"——主动注入微小的Mz来改善β的可观性
- 电机扭矩反馈可以作为KF额外的观测输入
