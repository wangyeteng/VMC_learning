# 质心侧偏角估计 (Sideslip Angle Estimation)

## 1. 一句话定义
> 质心侧偏角β是VMC中**最重要但最难获取**的状态量——没有廉价传感器可以直接测量它（GPS/光学传感器价格数千美元且受限），必须通过**融合IMU、轮速、方向盘转角等多种传感器信号**来估计。β估计的精度直接决定了VMC控制效果的上限。

## 2. 核心概念与公式

### 2.1 为什么β无法直接测量？

```
β = arctan(Vy / Vx)

需要的量:
  Vy: 侧向速度 → 没有廉价传感器能直接测量
      - GPS/RTK可测但需要双天线+开阔天空 ($1000+)
      - 光学传感器(Correvit) 可测但价格极高 ($10000+)
      - IMU积分积累巨大漂移 (1°/s bias → 30s后误差≈30°)

  Vx: 纵向速度 → 可以从轮速估计 (相对容易)
      - 但驱动/制动时存在滑移, 轮速 ≠ 车速
      - 需要四轮轮速 + 滑移率估计

所以: β估计实质上是 Vy估计 + Vx估计
```

### 2.2 三种估计方法对比

```
方法A: 运动学积分法 (Kinematic)

  思路: 从加速度积分得到速度
    dVy/dt = ay - r·Vx  (动力学关系)
    Vy = ∫(ay - r·Vx) dt + Vy0
    
  优点:
    ✓ 不依赖轮胎模型 → 不受轮胎参数不准的影响
    ✓ 简单直接
  缺点:
    ✗ IMU噪声和bias会积分积累 → 长时间漂移
    ✗ 初始条件Vy0很难知道
    ✗ 需要周期性重置 (如直行时Vy≈0)
  
  适用: 短时间、动态工况下的快速估计


方法B: 模型法 (Model-based)

  思路: 基于车辆模型和轮胎模型推断β
    ṙ = (lf·Fyf - lr·Fyr) / Iz
    β̇ = (Fyf + Fyr)/(m·Vx) - r
    Fyf = f(αf, Fz_f, μ),  αf = δ - β - lf·r/Vx
    Fyr = f(αr, Fz_r, μ),  αr = -β + lr·r/Vx
    
  优点:
    ✓ 不漂移 (基于模型, 不是积分)
    ✓ 可以利用已知的物理规律
  缺点:
    ✗ 依赖轮胎模型精度 (Cf/Cr不准 → 估计不准)
    ✗ 依赖路面μ估计 (μ不准 → 轮胎力不准 → β不准)
    ✗ 在极限工况(轮胎非线性区)误差大
  
  适用: 正常行驶工况, 轮胎在线性区


方法C: EKF/UKF融合法 (推荐!)

  思路: 用KF框架将方法A和方法B融合
  
  状态: x = [β, r, Vy, ay_bias]ᵀ
  预测步: 用车辆模型 (方法B)
  更新步: 用加速度关系约束 (方法A)
  
  优点:
    ✓ 兼具运动学法的动态响应和模型法的长期稳定
    ✓ 不确定性被KF自动处理
    ✓ 可以加入更多传感器 (GPS, 视觉里程计等)
  
  ★ 这是目前工业界和学术界的主流方案
```

### 2.3 EKF用于β估计的完整设计

```python
# EKF β估计器的设计

# 状态: x = [Vy, r, β]ᵀ  (或 [β, r]ᵀ 简化版)
# 注意: β = Vy/Vx, 如果Vx已知, 可以从Vy导出β

# 预测模型 (非线性):
#   Vẏ = (Fyf·cos(δ) + Fyr)/m - r·Vx
#   ṙ  = (lf·Fyf·cos(δ) - lr·Fyr)/Iz + Mz_add/Iz
#   其中 Fyf = f_MF(αf), Fyr = f_MF(αr)
#        αf = δ - arctan((Vy + lf·r)/Vx)
#        αr = -arctan((Vy - lr·r)/Vx)

# 观测:
#   y[0] = r (直接来自IMU陀螺仪)
#   y[1] = ay = Vẏ + r·Vx (来自IMU加速度计)

# EKF实现关键:
#  1. 在每一步计算雅可比矩阵 (∂f/∂x, ∂h/∂x)
#  2. 预测步: 用非线性模型做一步积分
#  3. 更新步: 用线性化的观测矩阵计算卡尔曼增益
#  4. 重新线性化 (在每次预测后)

# 雅可比计算 (解析/数值):
#  ∂f₁/∂Vy = -1/(m·Vx) · (∂Fyf/∂αf + ∂Fyr/∂αr)
#    其中 ∂Fy/∂α = 侧偏刚度 Cα (在线性区)
#               = 非线性表达 (在饱和区)
```

### 2.4 β估计的关键工况

| 工况 | β特征 | 估计难度 | 关键挑战 |
|------|-------|----------|----------|
| 直行 | β≈0 | ★★ | β几乎恒为0，估计器可能"睡着了" |
| 稳态转弯 | β≈常数 (~1-3°) | ★★★ | 模型不确定度主导 |
| 瞬态转向 | β快速变化 | ★★★★ | 需要好的动态响应 |
| 对开路面 | β突变 | ★★★★★ | μ估计同时出错，耦合误差 |
| 极限工况 | β>5°, 非线性 | ★★★★★ | 轮胎模型失效, 最需要β但又最难估计 |

### 2.5 改善β估计的额外信息源

```
1. GPS双天线航向:
   提供绝对航向角 ψ_GPS → 与 IMU 的 ψ̇=r 积分对比
   → 可约束r的bias → 间接改善β
   局限: 需要开阔天空, 城市峡谷/隧道不可用

2. 轮速差:
   转弯时左右轮速差 = tw·r → 提供独立于IMU的r观测
   → 可用于检测IMU gyro的bias

3. 视觉里程计 (VO):
   从摄像头估计 ego-motion → Vy和Vx的另一个来源
   局限: 光照/纹理依赖, 低附路面效果差

4. 主动激励:
   故意注入微小Mz (通过后轴差动) → 激发侧向动态
   → 改善β的可观性
   → 三电机天然适合! (后轴差动可以做到几乎不感知)

5. 多模型自适应:
   并行运行多个不同轮胎参数的EKF
   → 根据新息(inovation)选择最优
   → 适应轮胎磨损、胎压变化、路面变化
```

## 3. 我的理解

1. **β估计是VMC中最难的传感器融合问题**：它不是"选个好滤波器"就能解决的——它需要对车辆动力学、轮胎物理、传感器特性都有深刻理解。

2. **流体力学类比**: β估计 ≈ **湍流量的间接测量**
   - 你不能在流场中到处放探头（就像你不能直接测β）
   - 你只能测一些容易测量的量（速度、压力）→ 对应VMC中的IMU（r, ay）
   - 然后用物理模型 (RANS/车辆模型) 把难测量的量推断出来
   - 数据同化 (4D-Var) ≈ KF

3. **EKF的雅可比计算是关键**：
   - 如果你用了非线性轮胎模型 (Magic Formula), 雅可比需要包含 ∂Fy/∂α
   - Magic Formula的导数有解析表达式（虽然很复杂）
   - 或者用数值微分（慢但简单，100μs级对嵌入式也可接受）

4. **三电机平台可以做更多**：
   - 后轴差动可以"不引人注意地"注入激励信号来改善可观性
   - 电机扭矩反馈精确（电流→扭矩的映射很准）→ 可以作为额外的观测输入

## 4. 与易三方平台的关联

- 三电机可以在几乎不改变总驱动力的情况下产生横摆激励 → β可观性改善
- 电机扭矩的精确反馈 (±2%精度) → 可用于"扭矩平衡"法估计Vy
- 低速坦克转向时β的物理意义与传统行驶不同 → 需要特殊的β估计策略
