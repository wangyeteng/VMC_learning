# 坦克转向原理 (Tank Turn)

## 1. 一句话定义
> 坦克转向（Tank Turn / Pivot Turn）是一种利用**左右轮反向驱动**使车辆绕自身中心旋转的机动方式。在易三方平台上，通过后轴左右电机反向驱动，配合前轮最大转角，可以实现远小于常规的最小转弯半径，甚至接近原地掉头。

## 2. 核心概念与公式

### 2.1 坦克转向的物理原理

```
传统转向:
  前轮转角δ → 轮胎侧向力Fy → 横摆力矩 → 转弯
  最小转弯半径: R_min ≈ L/sin(δ_max) ≈ 5~6m (B级轿车)

坦克转向 (后轴差动):
  左右后轮反向驱动 → 一侧向前, 一侧向后
  → 直接产生巨大横摆力矩
  → 横摆力矩使车绕Z轴旋转
  
  产生的横摆力矩:
  Mz_tank = (T_rr - T_rl) · tw_r / (2·r_w)
          = 2·T_max · tw_r / (2·r_w)   ← 最大差动时
          = T_max · tw_r / r_w

  例: T_max=200Nm, tw_r=1.6m, r_w=0.35m
  → Mz_tank_max = 200 × 1.6 / 0.35 = 914 N·m

  作为对比, 方向盘打到头在20m/s时产生的横摆力矩约200~500 N·m
  → 坦克转向在低速时能产生远超方向盘的横摆力矩
```

### 2.2 坦克转向的运动学

```
三种坦克转向模式:

模式A: 后轴差动 + 前轮0° (纯差动转向)
  ┌────┐
  │ ↑  │ 前轮0° (直行方向)
  ├────┤
  │← →│ 后轮左右反向
  └────┘
  
  旋转中心: 大致在车身中心
  旋转角速度: r ≈ Mz_tank / B_total (B_total是总的旋转阻尼)
  
  特点: 转弯半径≈车身长度的一半 (~2.5m)
        对轮胎侧向磨损较大


模式B: 后轴差动 + 前轮最大转角 (协同转向)
  ┌────┐
  │↗ ↖│ 前轮最大转角
  ├────┤
  │← →│ 后轮左右反向
  └────┘
  
  旋转中心: 靠近后轴
  旋转角速度: r = r_tank + r_steer (叠加)
  
  特点: 最小转弯半径可接近车身对角线的一半
        效果最好, 但控制最复杂


模式C: 后轴差动 + 前轮差动制动 (如有前轴ESP)
  ┌────┐
  │↗  │ 前轮: 外前轮驱动, 内前轮制动(ESP)
  ├────┤
  │← →│ 后轮: 左右反向驱动
  └────┘
  
  旋转中心: 在内后轮附近
  旋转角速度: 最大 (所有轮子都在产生横摆力矩)
  
  特点: 最极端的转弯方式, 但能耗/磨损最大
        通常仅用于展示/越野脱困
```

### 2.3 坦克转向的控制策略

```python
# 坦克转向控制的关键要素

# 1. 进入条件判断
def can_activate_tank_turn(Vx, delta_sw, mode):
    """判断是否可以激活坦克转向"""
    if Vx > Vx_threshold:  # 通常 Vx_threshold ≈ 5~10 km/h
        return False  # 高速禁用, 危险
    if abs(delta_sw) < delta_threshold:
        return False  # 驾驶员没有明显转向意图
    if motor_temp > temp_limit:
        return False  # 电机温度过高, 不能反向满扭矩
    if mu < mu_min:  # 冰面上坦克转向无意义
        return False
    return True

# 2. 扭矩分配
def tank_turn_torque_allocation(r_des, Vx, delta):
    """坦克转向的扭矩分配"""
    # 后轴: 完全反向
    T_rl = -T_tank  # 一侧反向
    T_rr = +T_tank  # 一侧正向
    
    # 前轴: 根据情况
    T_front = f(Vx, delta)  # 可能是0, 可能是辅助驱动
    
    # 横摆力矩
    Mz = (T_rr - T_rl) * tw_r / (2 * r_w)
    
    return T_front, T_rl, T_rr, Mz

# 3. 退出条件
# - 车速超过阈值 → 逐渐减小差动, 恢复正常扭矩分配
# - 驾驶员松方向盘 → 退出坦克转向
# - 电机过热 → 降功率退出
```

### 2.4 坦克转向的限制与挑战

```
挑战1: 轮胎磨损
  后轮在横向滑动 → 轮胎严重磨损
  缓解: 仅低速使用, 限制单次持续时间

挑战2: 电机/逆变器发热
  反向驱动 = 一侧电机发电, 一侧电机耗电
  → 发电侧的电流需要通过逆变器回电池或消耗
  → 如果电池SOC高 → 回收困难 → 需要制动电阻消耗
  → 逆变器/电机发热远大于正常行驶
  
  热管理是坦克转向最大的工程约束!

挑战3: 驾驶员感知
  坦克转向时驾驶员感受与传统驾驶完全不同
  → 需要清晰的HMI提示当前模式
  → 退出时需要平滑过渡

挑战4: 侧向稳定性
  坦克转向时 β (质心侧偏角) 可能达到90°
  → 传统稳定性判据完全失效
  → 需要专门的坦克转向稳定性监控

挑战5: 路面损伤
  原地旋转对路面(尤其是沥青)有损伤
  → 建议仅在越野/非铺装路面使用
```

## 3. 我的理解

1. **坦克转向是三电机平台最直观的差异化功能**——传统车完全做不到，双电机也做不到（因为需要左右独立控制）。这是向领导展示VMC价值的绝佳案例。

2. **但坦克转向的工程挑战大于算法挑战**。算法上很简单（左右反向驱动），难点全在工程上：热管理、轮胎磨损、NVH、驾驶员体验。

3. **坦克转向的"展示价值"远大于"实用价值"**。用户一年可能用不了几次，但它是技术实力的象征——就像保时捷的Launch Control。

## 4. 与易三方平台的关联

- 易三方的后轴双电机是实现坦克转向的硬件基础
- 需要VMC专门维护一个"坦克转向状态机"来控制进入/维持/退出
- 前轴单电机的配置意味着坦克转向的协同效果稍弱于四电机（如仰望U8），但后轴差动已能独立实现
- 需要在功能安全层面限制坦克转向的使用场景
