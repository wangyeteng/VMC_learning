# 单电机失效补偿 (Fault-Tolerant Control)

## 1. 一句话定义
> 当三电机中的一个发生故障（无法输出扭矩或被强制关闭），VMC需要**在毫秒级时间内**重新分配剩余正常电机的扭矩，在保证车辆稳定可控的前提下，尽可能维持行驶能力（跛行回家）。这是三电机冗余性的核心价值体现，也是功能安全（ASIL D）要求的关键场景。

## 2. 核心概念与公式

### 2.1 三种单电机失效场景

```
场景A: 前轴电机失效
─────────────────────
  影响: 失去前轴驱动力
  剩余能力: 后轴双电机独立 (两驱)
  
  横摆力矩能力: 不变! ★
    → 前轴本来就不能差动 (有差速器)
    → 后轴双电机仍在 → 横摆力矩能力完整保留
    → 仅失去部分总驱动力
  
  补偿策略:
    1. 前轴扭矩清零 (或跟随转动)
    2. 后轴承担全部驱动 + 横摆力矩
    3. 总驱动力减小 (只有后轴)
    4. 通知驾驶员: "前电机故障, 请尽快靠边停车"
  
  危险性: ★★ (中等 — 横摆力矩还在, 动力减弱但可控)


场景B: 后轴单电机失效 (一侧)
───────────────────────────
  影响: 失去一侧后轮的主动驱动能力
  剩余能力: 前轴电机 + 对侧后轴电机
  
  横摆力矩能力: 大幅下降! ★★★ (最危险的失效模式)
    → 差动能力从"正反向全范围"降为"只能单向"
    → 如果左后失效 → 只能产生右转横摆力矩 (右后驱动)
    → 左转需要前轴制动辅助 → 横摆能力受限
  
  补偿策略:
    1. 立即切断失效电机的扭矩 (防止不对称扭矩)
    2. 健康后电机降低最大扭矩 (防止单侧驱动导致意外横摆)
    3. 前轴维持驱动, 同时准备ESP制动干预
    4. 横摆力矩需求分配给: 健康后电机 + 前轴ESP (如需)
    5. 限制车速: Vx_max降低 (安全保守)
    6. 通知驾驶员: "后电机故障, 请立即靠边停车"
  
  危险性: ★★★★ (横摆力矩大幅受限, 需要快速补偿)


场景C: 后轴双电机同时失效/后轴驱动系统故障
─────────────────────────────────────
  影响: 失去所有后轴驱动
  剩余能力: 仅前轴电机 (前驱)
  
  横摆力矩能力: 完全丧失! ★★★★★ (最危险)
    → 后轴差动能力=0
    → 仅靠方向盘转向 + ESP制动
    → 回到"传统前驱车"的水平
  
  补偿策略:
    1. 后轴两电机都切断
    2. VMC降级到"传统ESP模式"
    3. 仅前轴驱动 + ESP制动干预
    4. 严格限制车速: Vx_max < 50 km/h
    5. 通知驾驶员: "后驱系统故障, 请立即安全停车"
  
  危险性: ★★★★★ (回退到ESP-only, 驾驶体验显著下降)
```

### 2.2 失效检测与隔离时间要求

```
时间线要求:
  T0:       故障发生 (如IGBT击穿, 绕组短路, 位置传感器失效)
  T0+5ms:   MCU检测到异常 (电流/电压/转速突变)
  T0+10ms:  MCU上报故障给VMC (通过CAN/ETH)
  T0+12ms:  VMC识别故障, 决定降级策略
  T0+15ms:  VMC发出新的扭矩分配指令
  T0+25ms:  补偿扭矩到位, 车辆状态稳定

总时间窗口: < 30ms (约3个控制周期 @10ms周期)

关键: 在这30ms内车辆不能发生不可逆的危险状态
→ 如果后轴一侧突然失去扭矩(从+200Nm到0),
  在25ms内产生的意外横摆力矩 ≈ 200/0.35 × 0.8 = 457 N·m
  作用25ms ≈ 产生的横摆角速度偏差 ≈ 457/2500 × 0.025 = 0.0046 rad/s ≈ 0.26°/s
  → 这个量级在25ms内不会被驾驶员感知
  → 但如果补偿延迟到100ms以上 → 偏差会累积到危险水平
```

### 2.3 失效后的扭矩分配QP修改

```python
# 正常状态的QP:
# u = [T_fl, T_fr, T_rl, T_rr]
# u_min ≤ u ≤ u_max

# 后轴左电机失效时的QP:
# u = [T_fl, T_fr, T_rl_fixed=0, T_rr]  ← T_rl被固定为0
# u_rr_max = reduced_limit  ← 降低健康电机的上限(防止单侧过大扭矩)

# 修改后的控制效能矩阵:
# 原B:   [1/rw  1/rw  1/rw  1/rw]
#        [-a    a     -b    b   ]  , a=tw_f/2rw, b=tw_r/2rw
# 失效后: [1/rw  1/rw  0     1/rw]  ← 第3列被移除
#        [-a    a     0     b   ]

# 即: T_rl固定=0, 从决策变量中移除 → 3个决策变量 (T_f, T_rr)
# QP维度: 4→3 (在线修改即可)

# 约束变化:
# 后轴最大横摆力矩从 ±(T_max·tw_r/rw) 降为 ±(T_max·tw_r/(2·rw))
# → 单向横摆力矩减半!
```

### 2.4 各失效模式的VMC降级矩阵

| 失效 | VMC模式 | 最大横摆力矩 | 最大Vx | ASIL | 驾驶员通知 |
|------|---------|-------------|--------|------|-----------|
| 无 | 全功能 | 100% | Vmax | QM | 无 |
| 前电机 | 后驱VMC | 100% | Vmax | A/B | 黄色警报 |
| 后左/右电机 | 非对称VMC | ~40% | 80 km/h | C/D | 红色警报+限速 |
| 后双电机 | ESP-only | ~10% | 50 km/h | D | 红色警报+立即停车 |
| 转向失效 | 差动转向辅助 | ~60% | 30 km/h | D | 红色警报+立即停车 |
| 制动失效 | 电机回馈制动 | ~50% | 50 km/h | D | 红色警报+立即停车 |

## 3. 我的理解

1. **后轴单电机失效是最危险的场景**：它会打破后轴的对称性，产生意外的横摆力矩。VMC必须在~15ms内通过切断失效电机+调整健康电机来恢复对称。

2. **失效补偿不是"恢复全功能"，而是"安全地降级"**。目标不是让车继续像什么都没发生一样开——而是让驾驶员安全地把车停到路边。

3. **这个场景是VMC功能安全的"入学考试"**：如果你的VMC不能优雅地处理单电机失效，它就不具备ASIL C/D的资格。

4. **流体力学类比**: 失效补偿 ≈ **发动机空中停车的飞行控制**——飞行员（VMC）必须快速判断哪个发动机失效了，并重新配置控制面（扭矩分配）来保持飞机（车辆）稳定。

## 4. 与易三方平台的关联

- 三电机的关键卖点之一就是"冗余安全"——单电机失效仍可安全行驶
- 需要确认易三方是否有独立的电机切断电路（安全关断路径）
- 失效补偿逻辑需要进行大量的HIL/SIL测试（故障注入测试）
- 建议将"后轴单电机失效补偿"作为VMC开发的第一优先级安全功能
